====================
The two sum problem is a common problem in coding interviews. It states that given an array of integers and a target sum, find two elements in the array that add up to the target sum.

**Python Solution**
------------------

```python
def two_sum(nums, target):
    """
    Returns the indices of the two numbers that add up to the target sum.

    Args:
        nums (list): A list of integers.
        target (int): The target sum.

    Returns:
        list: A list containing the indices of the two numbers that add up to the target sum.
    """
    num_dict = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in num_dict:
            return [num_dict[complement], i]
        num_dict[num] = i
    return None

# Example usage:
nums = [2, 7, 11, 15]
target = 9
result = two_sum(nums, target)
if result:
    print(f"The indices of the two numbers that add up to {target} are {result}")
else:
    print(f"No two numbers in the list add up to {target}")
```

**Explanation**
---------------

1. Create an empty dictionary `num_dict` to store the numbers we have seen so far and their indices.
2. Iterate through the list of numbers `nums`.
3. For each number `num`, calculate its complement `complement` by subtracting it from the target sum `target`.
4. Check if the complement is already in the dictionary `num_dict`. If it is, it means we have found two numbers that add up to the target sum, so return their indices.
5. If the complement is not in the dictionary, add the current number and its index to the dictionary.
6. If we finish iterating through the list and haven't found two numbers that add up to the target sum, return `None`.

**Time Complexity**
------------------

The time complexity of this solution is O(n), where n is the length of the list of numbers, because we are iterating through the list once.

**Space Complexity**
-------------------

The space complexity of this solution is O(n), because in the worst case, we might need to store all numbers in the dictionary.

    """
    Returns the indices of the two numbers in the array that add up to the target sum.

    Args:
        nums (list): A list of numbers.
        target (int): The target sum.

    Returns:
        list: A list containing the indices of the two numbers that add up to the target sum.

    num_dict = {}

        num_dict[num] = i

5. If the complement is not in `num_dict`, add the current number and its index to `num_dict`.

The two sum problem is a classic problem in computer science where you're given a list of numbers and a target sum, and you need to find two numbers in the list that add up to the target sum.

**Python Solution**
------------------

```python
def two_sum(nums, target):
    """
    Returns two numbers in the list that add up to the target sum.

    Args:
        nums (list): A list of numbers.
        target (int): The target sum.

    Returns:
        tuple: Two numbers that add up to the target sum.
    """
    num_map = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in num_map:
            return (complement, num)
        num_map[num] = i
    return None

# Example usage
nums = [2, 7, 11, 15]
target = 9
result = two_sum(nums, target)
if result:
    print(f"Two numbers that add up to {target} are {result[0]} and {result[1]}")
else:
    print("No two numbers add up to the target sum")
```

**How it works**
----------------

1. Create an empty dictionary `num_map` to store the numbers we've seen so far and their indices.
2. Iterate through the list of numbers.
3. For each number, calculate its complement (the number that would add up to the target sum).
4. Check if the complement is in the `num_map`. If it is, return the complement and the current number.
5. If not, add the current number to the `num_map` with its index as the value.
6. If we reach the end of the list without finding a pair of numbers that add up to the target sum, return `None`.

**Time complexity**
------------------

The time complexity of this solution is O(n), where n is the length of the list of numbers. This is because we're doing a single pass through the list. The space complexity is also O(n), as we're storing the numbers in the `num_map` dictionary.
